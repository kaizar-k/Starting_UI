This code started as a generalised serial interface object, to connect to multiple custom microcontroller based data logging and tesing devices made by Zackery Matthews.

This sparked the idea to make a generalised frame work for making custom data logging, analysis, and interpretation software for various applications.
The basic specs for this application are:
  the ability to set up different user adjustable settings, experiment perameters, device connections and channels configurations per device  
  Multiple pages with different purposes and the ability to switch between them.
  pop up windows with adjustable settings for each page.
  a live plot of raw-incomming data.
  the ability to apply filters and analysis to incomming data and display the resultant plots without losing raw data.
  The ability to configure 1 or more plots to display live on the live plot window.
  the ability to create, update, delete and upload configureation files to plot these values to a positional / geometric argument, and produce a live heat map.
  The ability to import old dat and configuration files to view plots
    The ability to scroll through a timeline of previously collected data and generate a pseudo live heat map.

This is going to be a long term project which will grow as needs progress and skills develop. 

A core tennent of this build is scalability, readability and ease of editing.
Clarity, maintainability, and functionality will be chosen over brevity, neatness, or elegance.
